# Chron'O — interface prototype

Clickable HTML prototype of the Chron'O interface (orienteering timing software, SportIdent).
**Discussion support, not a specification.** All names, clubs and card numbers are invented.

- **Open it**: https://chron-o.github.io/maquette/ (GitHub Pages), or open `index.html` in a browser.
- It adapts to the screen: phone layout under 760 px, desktop layout above (scaled down on tablets).
- Bottom-left **« ▸ Démo »** panel: force desktop / phone, simulate a card read, unplug a reader or a screen, etc.

Main project: [Chron-O/chrono](https://github.com/Chron-O/chrono).
